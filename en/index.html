whoami

I am Benjamin Robles (krr), a computer engineer graduated from Pontificia Universidad Católica de Valparaíso, Chile. I currently build freelance and consulting software.

My default mode is fixing things: understanding how they work, removing friction and making systems work better, whether that is software, a home automation setup or a car. I work across the stack and enjoy reverse-engineering unfamiliar systems to build practical solutions.

Contact: me@krr.cl · github.com/cykrr

what i do

  • Speech and ML: Chilean Spanish ASR, Wav2Vec2 benchmarking and evaluation pipelines.
  • Product engineering: Next.js PWAs, FastAPI and PHP backends, Supabase and Gemini-powered workflows.
  • Systems programming: C++, Rust, Go, OpenGL, CLI tools, graphics and automation.
  • Workflow-first AI: Using AI to augment real workflows when it helps, rather than adding AI for its own sake.

Software & Projects

I build things, mostly to avoid using bloated corporate alternatives. Here are some active and past projects:

Current work

  • Inspector IA: Camera-based assistance for construction inspectors (ITOs): analysis of compliance, good practices and areas to improve.
  • WinControl: (GitHub) Daemon and app for launching Windows applications, changing volume and switching audio outputs. Started as a personal button board inspired by Elgato's Stream Deck.

Research

  • Chilean Spanish ASR: Benchmarking suite for robust Chilean Spanish ASR with Wav2Vec2, built as my degree project. Two-stage pipeline (transcribe, then evaluate) aimed at hardware-efficient experimentation: ablation studies, acoustic profiles and decoding strategies.

Open source

  • mdserve: (GitHub) HTTP server in C that serves Markdown straight from disk, built for notes kept in Git: no database, no proprietary format, just files.
  • kindle-dashboard: (GitHub) Native GTK dashboard for Kindle devices. Home Assistant control with direct API integration, an e-ink-optimised UI and real button events.
  • graph: (GitHub) 3D function visualiser built from scratch on OpenGL.
  • krr-ge: C++ game engine template on OpenGL 4.5 Core (GLFW, GLM, Glad).
  • C/C++ Systems: HTTP servers, CLI tools and graphics written in C, C++ and Rust.

Client work

  • Floreria Coral: Built www.floreriacoral.cl a Wordpress + WooCommerce based E-commerce site.
  • PlanetariumVR: (GitHub) VR educational platform about the solar system, with collaborative building and Wii remote tracking.
  • Bio Lab Escape: Educational endless-runner about cell biology: mitosis, meiosis and genetic material organisation.

WARNING: The services hosted on the home server may go down if my power cuts out or if I'm messing with Docker containers. Uptime is a suggestion, not a guarantee. For more info. check Status.
