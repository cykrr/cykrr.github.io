 Florería Coral: tienda online, pagos y pedidos para un negocio local 
 
 Desarrollador WordPress / Full Stack | Proyecto Individual 
 
 floreria.tags.e-commerceNegocio LocalWordPressWooCommerceWebpayAI-ready 
 
 
 
 
 
Resumen
 
Florería Coral es una tienda online para una floristería local ubicada en Santa Inés, Viña del Mar. El sitio permite explorar el catálogo, pagar con Webpay y crear pedidos desde un flujo de compra pensado para clientes móviles.
 
El proyecto combina WordPress y WooCommerce con integraciones personalizadas para adaptar la tienda a la operación real del negocio: productos, despacho, disponibilidad y pedidos en un mismo flujo.
 
 
 
Características y Funcionalidades
 
1. Catálogo y compra desde el móvil
 
Una tienda responsive para que los clientes puedan descubrir arreglos, revisar precios y comenzar un pedido desde cualquier dispositivo.
 
2. Pagos y creación de pedidos
 
Integré el flujo de WooCommerce con Webpay para recibir pagos online y crear pedidos con la información necesaria para preparar y despachar cada compra.
 
3. Información preparada para agentes de IA
 
El sitio expone un documento llms.txt y endpoints públicos de solo lectura para productos, políticas de despacho y disponibilidad. Así, un agente puede consultar información confiable y derivar al cliente al checkout web.
 
 
 
El Desafío
 
El desafío era convertir la operación de una floristería tradicional en una experiencia de compra online clara, sin perder las reglas específicas del negocio: zonas de despacho, retiro en tienda, horarios y preparación de pedidos.
 
 
 
Qué demuestra
 
Este proyecto demuestra que una instalación WordPress puede convertirse en una herramienta de comercio útil cuando se conecta con pagos, reglas operativas y datos accesibles para software moderno. La entrega está disponible en llms.txt y en endpoints públicos documentados.
