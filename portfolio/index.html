Infraestructura y Servicios

La mayor parte de mi trabajo pesado se realiza en mi homelab (una mezcla de Raspberry Pi 5 y WSL) en mi casa. A continuación se muestran los servicios que expongo en la web.

Voz-CL — voz-cl.krr.cl
Recolector de voz anónimo. Reúne audio para entrenar modelos ASR de Wav2Vec2/Whisper para español chileno, la base de mi investigación de título.
Biolab Escape — krr.cl/biolab-escape
Un juego de biología celular que desarrollé en la universidad con algunos amigos.

Software y Proyectos

Construyo cosas, principalmente para evitar usar alternativas corporativas infladas. Aquí hay algunos proyectos activos y pasados:

En curso

  • Inspector IA: Asistencia por cámara para inspectores técnicos de obra (ITO): análisis de cumplimiento, buenas prácticas y puntos a mejorar.
  • WinControl: (GitHub) Demonio y app para lanzar aplicaciones de Windows, cambiar el volumen y conmutar salidas de audio. Empezó como una botonera personal inspirada en el Stream Deck de Elgato.

Investigación

  • ASR de Español Chileno: Suite de benchmarking para ASR robusto de español chileno con Wav2Vec2, desarrollada como proyecto de título. Pipeline en dos etapas (transcribir y evaluar) orientado a experimentar con hardware limitado: estudios de ablación, perfiles acústicos y estrategias de decodificación.

Código abierto

  • mdserve: (GitHub) Servidor HTTP en C que sirve Markdown directamente desde el disco, pensado para notas versionadas en Git: sin base de datos ni formato propietario, solo archivos.
  • kindle-dashboard: (GitHub) Panel GTK nativo para dispositivos Kindle. Control de Home Assistant con integración directa a la API, interfaz optimizada para tinta electrónica y eventos reales de botones.
  • graph: (GitHub) Visualizador de funciones en 3D construido desde cero sobre OpenGL.
  • krr-ge: Plantilla de motor de juego en C++ con OpenGL 4.5 Core (GLFW, GLM, Glad).
  • Sistemas C/C++: Servidores HTTP, herramientas de línea de comandos y gráficos escritos en C, C++ y Rust.

Trabajo para clientes

  • Florería Coral: Construí www.floreriacoral.cl un sitio de comercio electrónico basado en Wordpress + WooCommerce.
  • PlanetariumVR: (GitHub) Plataforma educativa de realidad virtual sobre el sistema solar, con construcción colaborativa y seguimiento mediante control de Wii.
  • Bio Lab Escape: Juego educativo de carrera infinita sobre biología celular: mitosis, meiosis y organización del material genético.

ADVERTENCIA: Los servicios alojados en el servidor doméstico pueden caerse si se corta la energía o si estoy manipulando contenedores Docker. El tiempo de actividad es una sugerencia, no una garantía. Para más información, consulte Estado.
